# 04. 交登录，别把密码贴进对话

**结果：没有 API / 没有 MCP 的公司软件，也能用。你点完登录，bot 拿的是同一浏览会话，不是你的密码。**

## 目标

真实公司软件大多没有干净的 API。正确路径是：bot 在云端浏览器里走到登录墙，把屏幕交给你，你认证，点完成，它在**同一浏览器实例**上接着干。

## 做法

1. 让 bot 打开目标站点，自己走到登录页。
2. 出现登录墙时，它把画面交给你——你在那一层完成 2FA / SSO / 通行密钥。
3. 你点 done。bot 继续，拿的是 session。
4. **永远不要**把密码、验证码、恢复码、API key 打进聊天框。
5. API key 走平台提供的**专用密文框**。ThursdAI 演示里写得很直白：*The bot doesn't see your API keys ever.* 贴进对话会进记忆、进日志，也可能被别的 bot 误用。
6. 验证码 / 2FA / 付款：接管远端桌面，做完，交回去。侧边电脑图标变紫表示它正在动；远程桌面右上角有 teach-a-task，用来接管或演示。
7. 云端浏览器里已经登录的 Google / SSO，可以直接复用，不必再给一套钥匙。

一条硬规则：如果某个工具或某个提示让你把密码或 key 粘进对话，那就是错路。停。

## 为什么重要

Bot 拥有电脑和登录态，才能在你睡觉时行动。但秘密不应进入模型上下文：对话会被记住、被检索、被误用到别的线程。Session 能撤；贴出去的密码撤不干净。

## 反例

- 「密码是 `...`，验证码发你。」这是把钥匙铸进日志。
- 登录墙出现后让 bot「猜一下常用密码」或从别处的笔记里读。
- 在不可信页面上完成登录，或把个人 Apple / 银行账号交给工作 bot。能交会话，不代表该交这个账号。
