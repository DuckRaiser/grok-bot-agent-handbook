# 01. 装好，先见 Chief

**结果：桌面里有一个名叫 Chief 的 bot。你用一件 30 秒能核验的真事跟它对过一次。**

## 目标

先把它装成日常工具，而不是再开一个浏览器标签。第一个对话对象是 Chief：它的工作不是包办一切，而是在你不知道该找谁时接住，之后再统筹其他专家。

## 做法

1. 装 **桌面端**（macOS）。用 Grok 或 Cursor 登录。不要把它当网页聊天用。
2. 界面像即时通讯：左边是具名 bot 列表，右边是对话。
3. 起始 bot 就是 **Chief**。先当总机，后当协调人。
4. 第一份活必须同时满足：
   - 真的（不是「用一句话介绍量子力学」）
   - 小
   - **30 秒内能在真实工具里核对**（日历多了一条、草稿箱多了一封、Notion 多了一行）

例：把今天 4 点后的日程列成三条；把收件箱里最新一封客户邮件起草回复（不发送）；把桌面某张截图里的数字填进你指定的表格。

做完你去核。对了，才有资格谈后面九步。

## 为什么重要

后面九步的目标是**学会把更大的活交给它**。第一枪如果是脑筋急转弯，你学到的是模型会不会答题，不是这个职位值不值得托付。

Chief 一开始不要承担 Inbox + 报销 + 招聘。它负责分诊：这事该谁，缺谁就说缺谁。

## 可套用模板

第一句可以很短，但必须带核验点：

```
Look at today's calendar after 16:00.
List the next 3 events as: time · title · who.
Do not invent events. If the calendar tool fails, say so.
```

## 反例

- 装完先问「你能做什么」。那是产品导览，不是委托。
- 第一份活无法在真实系统里核对（写一首诗、总结一篇你没给它的文章）。
- 把 Chief 当成唯一员工，后面所有事都堆在同一条线程。记忆会糊，问责会糊。
